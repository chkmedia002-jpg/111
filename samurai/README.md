# 三日月の武者 — 武士 3D 模型（已綁定骨架與動畫）

依參考圖（黑漆大鎧、金色三日月前立、背負白色旗指物、雙手持太刀斜舉的弓步姿勢）以程式化方式建模（three.js）。

| 檔案 | 說明 |
| --- | --- |
| `samurai.glb` | glTF 2.0 二進位檔（約 11 MB）：蒙皮網格＋骨架＋4 段動畫，可直接匯入 Blender、Unity、Unreal、Godot |
| `index.html` | 互動式檢視器：切換動作、顯示骨架、拖曳旋轉。會讀取同資料夾的 `samurai.glb`，需用網頁伺服器開啟（例如 `npx serve`，或 GitHub Pages） |
| `src/samurai.js` | 組裝與蒙皮烘焙 |
| `src/rig.js` | 骨架、IK 姿勢與動畫 |
| `src/head.js` / `armor.js` / `limbs.js` / `weapons.js` | 頭部與兜、鎧甲與背旗、四肢、刀具的建模 |
| `src/kit.js` | 共用幾何工具（掃掠、旋轉體、繩、彎曲板件等） |
| `build.mjs` | 產生 `samurai.glb` 與 `index.html` |

## 模型結構

- 單位：公尺，+Y 朝上，人物面向 +Z；綁定姿勢（rest pose）為中段構（雙手持刀於身前）。
- 約 47 萬三角面，23 種 PBR 材質，分成 40 個網格區塊（每塊少於 65,536 個頂點，索引用 16 位元），共用同一副骨架。
- 頂點資料以 KHR_mesh_quantization 量化（位置 14 位元、法線 10 位元、權重 8 位元），檔案約 11 MB。
- 細節：
  - **臉**：高解析網格雕出眉骨、眼窩、鼻、顴骨、嘴唇、下巴；眼球有眼白、虹膜、上下眼瞼；眉毛、八字鬍、山羊鬍都是一根根髮絲。
  - **兜**：32 道筋的鉢、多層金色天邊、三條篠垂、帶鉚釘的腰卷、金邊眉庇、五段錣、帶家紋的吹返、厚金三日月前立與鍬形台。
  - **鎧甲**：札板上緣為一片片圓頭小札，素懸縅（成對白繩），最下段紅色菱縫與耳糸；冠板金覆輪與菊座金物；胸板、背板、肩上、總角結。
  - **四肢**：布褶袖、鎖甲上帶金邊龜甲金、三片篠籠手；五指分開握刀，手背有手甲；袴有布褶；臑當有鎖、五條篠、立擧、絞繩綁結；分趾足袋與編織草鞋。
  - **刀具**：鎬造刀身與刃紋、切先、鈨、鏤空鍔與切羽、鮫皮與交叉柄卷、目貫；鞘有鯉口、栗形與紅色下緒；腰間脇差。
  - **背旗**：布褶旗面、黑色丸に三日月紋（兩面）、乳（旗環）、受筒與合當理。

## 骨架（19 根）

```
Hips
├─ Spine
│  ├─ Neck ─ Head
│  ├─ Shoulder_R ─ UpperArm_R ─ LowerArm_R ─ Hand_R ─ Katana
│  └─ Shoulder_L ─ UpperArm_L ─ LowerArm_L ─ Hand_L
├─ UpperLeg_R ─ LowerLeg_R ─ Foot_R
└─ UpperLeg_L ─ LowerLeg_L ─ Foot_L
```

- 肢體骨骼的 +Y 沿骨頭方向、+Z 指向關節彎曲方向（膝向前、肘向下外）。
- 鎧甲多為剛體，大部分頂點 100% 綁在單一骨頭上；跨關節的部位做雙骨混合：袴的臀部（Hips/UpperLeg）、草摺下段跟隨大腿、大袖一半跟肩一半跟上臂。
- 太刀是 `Hand_R` 的子骨頭，可在引擎中單獨掛載或替換武器。

## 動畫

| 名稱 | 長度 | 說明 |
| --- | --- | --- |
| `Idle` | 2.4 s 循環 | 中段構待機，帶呼吸起伏 |
| `Walk` | 1.0 s 循環 | 原地步行（in-place），持刀於中段；對應前進速度約 0.67 m/s |
| `Attack` | 1.5 s | 舉刀過右肩 → 踏步 → 袈裟斬 → 殘心 → 回到中段構（首尾與 Idle 相接） |
| `Pose_Reference` | 2.4 s 循環 | 參考圖的弓步斜舉姿勢 |

動畫以控制點（腰、腳、刀的位置與方向）描述，每幀用兩段 IK 解出手臂與腿的骨頭旋轉後烘焙成關鍵影格（30 fps），所以雙手始終握在刀柄上、腳踩在地面上。要調整動作，修改 `src/samurai.js` 中的 `idle` / `walk` / `attackKeys` / `reference` 再重新建置。

## 重新建置

```bash
npm install  # 匯出用；檢視器從 CDN 載入 three@0.147.0（傳統 script 版本，相容性較好）
node build.mjs
```
