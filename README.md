# 鋼鐵黎明 2050 (Steel Dawn 2050)

類似《紅色警戒 2》的即時戰略網頁遊戲。故事設定在 2050 年,稀土枯竭引發全球衝突,戰場上有雷射與電磁砲,但整體仍偏寫實。

## 如何遊玩
直接用瀏覽器開啟 `index.html`,不需要安裝任何東西,也不需要伺服器。

## 特色
- 斜 45 度等角視角,像素風格,畫面全部由程式繪製
- 兩大陣營
  - **大西洋聯盟**:雷射步兵、獵鷹偵察車、赫利俄斯雷射戰車、日冕光束砲車、雷射防禦塔
  - **歐亞協約**:反坦克火箭兵、狼獾突擊車、雷神重型戰車、電磁軌道砲車、電磁砲塔
- 經濟系統:採集車自動採礦並運回精煉廠(金色稀土礦,中央有高價值的藍晶礦)
- 電力系統:電力不足時生產速度減半,防禦塔也會停擺
- 科技需求:電廠 → 精煉廠/兵營 → 戰車工廠 → 科技中心
- 戰爭迷霧、小地圖、編組、集結點、修理與變賣
- 電腦對手(簡單/普通/困難):會自己蓋基地、採礦、防守,並分波進攻
- 合成音效與語音播報(單位生產完成以英語播報「Unit ready」,其餘為中文;依瀏覽器是否支援)

## 操作

| WASD / 方向鍵 / 滑鼠移到邊緣 / 中鍵拖曳 | 移動視角 |

## 進階玩法
- **老兵等級**:單位擊殺累積經驗,升為老兵(⌃)與精英(⌃⌃)後傷害、射速、防禦提升,精英會自動回血。
- **戰鬥工程師**:選取後右鍵點敵方建築即可佔領;點己方受損建築可立即修好。
- **超級武器**(需科技中心,各方限一座,充能 5 分鐘):
  - 大西洋聯盟「天穹軌道雷射」:從軌道發射持續灼燒的雷射光束
  - 歐亞協約「高超音速導彈井」:大範圍毀滅性打擊

## 高精細畫面
- 以螢幕原生解析度繪製(高 DPI 螢幕自動加倍),**滑鼠滾輪可縮放**,放大後可看清模型細節
- 戰車:履帶節、負重輪、斜面裝甲、側裙板、迷彩、艙蓋、頭燈尾燈、天線、反應裝甲、砲口制退器
- 步兵:頭盔與面罩、防彈背心、背包、手臂與步行動畫、各式武器
- 建築:窗戶(部分亮燈)、欄杆、空調、管線、閃爍警示燈、塔吊、停機坪、太陽能板、雷達
- 地形:草葉、碎石、沙紋、水岸泡沫、地形邊界混色、柔和戰爭迷霧

## 時代選擇:1592 壬辰之役(明朝)
主選單可切換年代。明朝時代為**三國混戰**(玩家 + 兩個電腦,電腦之間也會互相攻擊),電力改為糧草。

**資源採集**:運輸牛車可以採集銀礦、砍樹取木材、採岩石取石材,運回資源集散所(明:轉運所、日:蔵屋敷、朝:物資庫)後都換算成銀兩。銀礦效率最高、會再生;木材與石材採完就消失,樹林砍光後會留下樹樁並開出新的通道;大岩石會隨開採逐漸縮小,採完後完全消失。每個基地旁都有一群可開採的大岩石。銀礦畫成帶銀脈的礦石與銀錠(中央為金礦)。每輛牛車輪流偏好不同資源,也可以右鍵點樹林或岩石指定採集。

| 陣營 | 步兵 | 騎兵/車 | 重兵器 | 防禦塔 | 奇兵(超級武器) |
|---|---|---|---|---|---|
| 大明 | 鳥銃手、狼筅長槍兵 | 遼東鐵騎、偏廂戰車 | 大將軍砲 | 敵台 | 火龍出水 |
| 日本 | 鐵砲足輕、武士 | 騎馬武者、大筒車 | 焙烙投石車 | 鐵砲櫓 | 火攻之陣 |
| 朝鮮 | 弓手、殺手 | 騎射手、華車 | 震天雷砲 | 箭樓 | 神機箭陣 |

- 新武器類型:近戰(長槍克制騎兵)、弓箭、火繩槍(會冒煙)、實心砲彈、華車一次齊射多支神機箭、焙烙火罐(落地起火)
- 各國建築風格不同:明朝城樓與紅牆、日本天守閣與白壁、朝鮮丹青彩繪屋簷

## 美術圖素材
1. 依照 `docs/ART_PROMPTS.md` 用生圖 AI 製作圖片,存成 `art/src/單位代號.png`(或 .webp),例如 `art/src/jp_inf2.webp`
2. 執行 `python3 tools/pack_sprites.py`(需要 Pillow):自動去背、裁切、找腳底位置、縮放,產生 `js/sprites_data.js`
3. 執行 `python3 build.py` 重新產生單一 HTML

動畫畫格命名為 `代號_狀態_01.png`、`代號_狀態_02.png`…(狀態:`idle` 待命、`walk` 步行、`attack` 攻擊、`death` 死亡),或一張橫向排列的精靈圖表 `代號_狀態.png`。步行依移動距離換格,攻擊依攻擊節奏換格。

建築圖命名為 `陣營_類型.png`(例:`jp_barracks.png`),陣營專屬建築用原代號(例:`jp_turret.png`);圖片會自動對齊地面菱形格子,施工時由下往上長出。

有美術圖的單位會改用圖片顯示(含走路彈跳、攻擊前衝、自動左右翻轉),沒有圖的單位維持程式繪製。
