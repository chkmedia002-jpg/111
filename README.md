# 鋼鐵黎明 2050 (Steel Dawn 2050)

類似《紅色警戒 2》的即時戰略網頁遊戲。故事設定在 2050 年,稀土枯竭引發全球衝突,戰場上有雷射與電磁砲,但整體仍偏寫實。

## 如何遊玩
直接用瀏覽器開啟 `index.html`,不需要安裝任何東西,也不需要伺服器。

## 特色
- 斜 45 度等角視角,像素風格,畫面全部由程式繪製
- 兩大陣營
  - **大西洋聯盟**:雷射步兵、獵鷹偵察車、赫利俄斯雷射戰車、日冕光束砲車、雷射防禦塔
  - **歐亞協約**:反坦克火箭兵、狼獾突擊車、雷神重型戰車、電磁軌道砲車、電磁砲塔
- 經濟系統:採集車自動採礦並運回精煉廠(金色稀土礦,中央有高價值的藍晶礦)
- 電力系統:電力不足時生產速度減半,防禦塔也會停擺
- 科技需求:電廠 → 精煉廠/兵營 → 戰車工廠 → 科技中心
- 戰爭迷霧、小地圖、編組、集結點、修理與變賣
- 電腦對手(簡單/普通/困難):會自己蓋基地、採礦、防守,並分波進攻
- 合成音效與中文語音播報(依瀏覽器是否支援)

## 操作
| 操作 | 功能 |
|---|---|
| 左鍵 / 拖曳 | 選取 / 框選 |
| 右鍵 | 移動、攻擊 |
| Ctrl + 右鍵 | 攻擊移動 |
| WASD / 方向鍵 / 滑鼠移到邊緣 / 中鍵拖曳 | 移動視角 |
| Ctrl+1~9 / 1~9 | 編組 / 叫出編組 |
| X / H / P / F1 | 停止 / 回基地 / 暫停 / 說明 |

在側欄點選建築開始建造,完成後點擊「就緒」圖示,再到地圖上放置。

## 程式結構
```
index.html      介面
style.css       樣式
js/data.js      單位、建築、武器數值
js/map.js       地圖生成、A* 尋路
js/game.js      遊戲邏輯(生產、戰鬥、採礦、迷霧)
js/ai.js        電腦對手
js/render.js    等角像素渲染
js/ui.js        側欄、小地圖、滑鼠鍵盤操作
js/audio.js     音效與語音
js/main.js      主迴圈
```

## 進階玩法
- **老兵等級**:單位擊殺累積經驗,升為老兵(⌃)與精英(⌃⌃)後傷害、射速、防禦提升,精英會自動回血。
- **戰鬥工程師**:選取後右鍵點敵方建築即可佔領;點己方受損建築可立即修好。
- **超級武器**(需科技中心,各方限一座,充能 5 分鐘):
  - 大西洋聯盟「天穹軌道雷射」:從軌道發射持續灼燒的雷射光束
  - 歐亞協約「高超音速導彈井」:大範圍毀滅性打擊

## 高精細畫面
- 以螢幕原生解析度繪製(高 DPI 螢幕自動加倍),**滑鼠滾輪可縮放**,放大後可看清模型細節
- 戰車:履帶節、負重輪、斜面裝甲、側裙板、迷彩、艙蓋、頭燈尾燈、天線、反應裝甲、砲口制退器
- 步兵:頭盔與面罩、防彈背心、背包、手臂與步行動畫、各式武器
- 建築:窗戶(部分亮燈)、欄杆、空調、管線、閃爍警示燈、塔吊、停機坪、太陽能板、雷達
- 地形:草葉、碎石、沙紋、水岸泡沫、地形邊界混色、柔和戰爭迷霧
